# JobTrack 
JobTrack - Career Application Tracker JobTrack is a full-stack job application tracking system built with Python, Streamlit, Pandas, and MySQL. It provides a clean dashboard for organizing job applications, monitoring application progress, and managing important details throughout the recruitment process.  Features Secure user signup and login with bcrypt password hashing Add and manage job applications Track application statuses: Applied, Interview, Rejected, and Selected Edit application details and interview dates Delete applications with confirmation Search applications by company name Filter applications by status View dashboard statistics and status analytics Review recent applications Export application records as a CSV file Persistent MySQL database storage Responsive Streamlit interface with custom styling Technology Stack Frontend: Streamlit Backend: Python Database: MySQL Data processing: Pandas Authentication: bcrypt Database connector: MySQL Connector/Python Purpose JobTrack helps job seekers replace scattered spreadsheets and notes with a centralized career dashboard. Users can record opportunities, follow each application's progress, manage interview information, and review their overall job-search activity from one interface.
